# Mini-Processor for BCD Arithmetic Operations (IE1044)

## Description
Mini-Processor that performs **BCD arithmetic operations** (Addition, Subtraction, Multiplication) on 1-digit BCD inputs. Outputs a 2-digit BCD result and indicates overflow if the result exceeds 99. Designed and simulated using **Proteus**.

## Features
- BCD Adder with correction logic
- BCD Subtractor using two’s complement and correction
- BCD Multiplier (array or shift-add based)
- Multiplexer for operation selection
- Registers for input/output storage
- Overflow detection

## Inputs
- Two 1-digit BCD numbers (4-bit each)
- 2-bit control signal to select operation

## Outputs
- 2-digit BCD result (max 99)
- Overflow flag

## Simulation & Testing
- Designed and simulated in **Proteus**
- Verified with multiple test cases for all operations

## Files Included
- Circuit diagrams for individual components
- Integrated mini-processor design
- Simulation screenshots and files
- Written report (PDF/Word)

## Usage
1. Open the Proteus project file.
2. Simulate the circuit.
3. Select the operation via the control input.
4. Observe the 2-digit BCD output and overflow flag.
